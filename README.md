# Multiverse Hero Creator

A fast, free character creator and sheet manager for the Multiverse d616 tabletop role-playing system. Runs directly in your browser – 100% client-side and offline-capable, no installation or external server required.

---

## 🚀 How to Launch

* **Recommended:** Double-click `Start_Hero_Creator.bat`
* **Alternative:** Open `index.html` in any modern web browser (Edge, Chrome, Firefox, Safari, etc.)

---

## 🦸 Features

* **Character Creation & Editing:**
  * Select Rank 1 to 6 with automatic rule validation (Attribute caps, point budgets, Karma, damage multipliers).
  * Automatic calculation of Health, Focus, Defenses, and M-Dice damage bonuses.
  * Custom background details (Origin & Occupation), Movement Modes, Profile, and Notes.

* **Powers, Traits & Tags:**
  * Comprehensive compendium with instant search and 1-click additions.
  * Core rulebook support for trading unused Powers into additional Traits or Ability Points.
  * Full freedom to add custom Powers, Traits, and Tags.

* **Character Portrait & Printable Sheet Preview:**
  * Insert a custom character image with dynamic width/height sizing controls.
  * Real-time printable sheet preview formatted for clean A4 printing.
  * 1-click print or "Save as PDF" directly from the browser.

* **Save, Load & Share:**
  * Automatic local browser storage (`localStorage`) to keep multiple heroes saved across sessions.
  * Export and import characters as `.json` files for safe backups or sharing.

* **Settings & Multilingual Support:**
  * 5 supported languages: English, German, Spanish, Italian, and French (official game terms remain in English).
  * Dark and Light theme toggle.
  * Toggleable rule enforcement ("Follow Rules").
